## 已知架构差异（非功能缺失）

| 差异项   | React                     | Next.js         | 说明                     |
| ----- | ------------------------- | --------------- | ---------------------- |
| 路由缓存  | KeepAlive（Activity + LRU） | 不支持             | 架构限制，非 bug             |
| 认证传输层 | localStorage + Bearer     | httpOnly Cookie | 设计决策不同，API Contract 一致 |
